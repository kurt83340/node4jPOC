# Feux verts de Julien

Projet d'apprentissage qu'il finance : il délègue les choix réversibles et garde ceux qui engagent.

- « Tu tranches » : je décide, mais je donne ma préférence et les chemins écartés, avec leur raison, avant de
  valider ; la doc versionnée le note (« choix délégué par Julien », « validé par Julien »).
- J'attends son choix pour une fusion, une dépense, une publication (Jira, page partagée), un changement IAM, ou un
  réglage de son environnement global (lui demander d'abord s'il s'en sert).
- Aucun appel payant sans son feu vert, estimation annoncée ; plafonds : ADR-0010, ADR-0013, ADR-0016.
